# Shopping Cart System (Part 2)

## 📖 Project Overview

This is a C# Console-based Shopping Cart System enhanced with advanced cart features, checkout validation, receipt generation, stock alerts, and order history.

The program allows users to browse products, search items, add to cart, manage cart contents, and complete purchases.

---

## Part 2 Features

### Cart Management
- View Cart
- Remove Item
- Update Quantity
- Clear Cart
- Checkout

### Product Search
- Search products by name

### Product Categories
- Filter by category:
  - Food
  - Electronics
  - Clothing

### Low Stock Alert
- Displays products with stock less than or equal to 5 after checkout

### Payment Validation
- Payment must be numeric
- Payment must be enough
- Calculates change automatically

### Receipt System
- Receipt Number
- Date and Time
- Purchased Items
- Grand Total
- Final Total
- Payment
- Change

### Order History
- Stores completed transactions

### Improved Validation
- Better menu input validation
- Numeric checking
- Invalid choice prevention
